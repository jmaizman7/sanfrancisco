# Centro Médico Familiar San Francisco - Landing

Sitio estático: index.html + carpeta images/ (sin build).

## Subir a Vercel
- Arrastrar y soltar: vercel.com/new y sube esta carpeta completa.
- CLI: `npm i -g vercel` y dentro de la carpeta `vercel --prod`.
- Framework Preset: Other. Sin Build Command. Output Directory vacío.
